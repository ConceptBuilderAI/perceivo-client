# Security Policy

Thank you for helping keep `perceivo-client` and its users safe.

## Supported versions

Security fixes are released for the latest minor version only.

| Version | Supported |
| --- | --- |
| 1.0.x | Yes |
| < 1.0 | No |

Upgrade to the latest release to receive security fixes.

## Reporting a vulnerability

**Do not report security vulnerabilities through public GitHub issues, discussions or pull
requests.**

Report them privately through either channel:

- **Email:** [security@perceivo.ai](mailto:security@perceivo.ai)
- **GitHub:** open a private advisory from this repository's **Security** tab, using
  **Report a vulnerability**
  ([GitHub private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)).

Please include as much of the following as you can:

- a description of the vulnerability and its impact;
- steps to reproduce it, such as proof-of-concept code or a minimal example;
- the affected versions and your environment;
- any suggested fix.

## What to expect

- We acknowledge a report within 3 business days.
- We send an assessment and an expected timeline within 10 business days.
- We keep you informed of progress toward a fix.
- We credit you in the release notes and any advisory, unless you prefer to remain anonymous.

## Disclosure

We follow coordinated disclosure. Please give us a reasonable opportunity to investigate and release
a fix before disclosing the issue publicly. We will agree a disclosure timeline with you.

## Scope

This policy covers the code in this repository: the Python client, the request-signing reference
implementation and the build and release tooling. Vulnerabilities in the hosted
Perceivo platform or its API can be reported through the same channels.
